zunda-upload プライバシーポリシー

  1. このツールは、運営者本人のGoogleアカウントだけで使います。ほかの人のアカウントでログインすることはありません。
  2. YouTube Data API と YouTube Analytics API を使い、運営者のチャンネルへの動画のアップロード・公開予約・タイトルや説明やサムネイルの設定と、運営者のチャンネルの再生数・視聴維持率などの統計の取得だけを行います。
  3. 取得したデータとログイン情報（トークン）は、運営者のパソコンの中だけに保存します。第三者に提供・販売・共有することはありません。
  4. 広告や、利用者の追跡には使いません。
  5. Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
  6. アクセス権の取り消しは、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでもできます。
